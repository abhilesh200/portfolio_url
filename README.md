## 🚀 Featured Projects

### 🧬 CRISPR Off-Target Prediction

**Deep Learning | CNN | Bioinformatics | Streamlit**

An end-to-end machine learning project for predicting potential **CRISPR-Cas9 off-target activity** from DNA sequences.

**Key highlights:**

* Combined CIRCLE-seq and GUIDE-seq datasets
* DNA sequence preprocessing and one-hot encoding
* Feature engineering using mismatch count and GC content
* CNN-based sequence feature extraction
* Hybrid neural network architecture
* Focal Loss for class imbalance
* ROC-AUC and PR-AUC evaluation
* Interactive Streamlit prediction application

🔗 **Repository:**
https://github.com/abhilesh200/crispr-off-target-prediction
